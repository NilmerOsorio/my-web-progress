# 📋 HTML Lists Practice

In this small project, I reviewed how to use **ordered lists (`<ol>`) and unordered lists (`<ul>`) in HTML** to organize and display information in a clear way.

I practiced creating an ordered list to show my **top three favourite anime**, where the order is important, and an unordered list to display some of my **favourite songs**, where the order doesn't matter.

## 🛠️ What I Practiced

* 🔢 Using `<ol>` to create **ordered lists** with numbered items.
* 📌 Using `<ul>` to create **unordered lists** with bullet points.
* 📝 Using `<li>` to define each item inside a list.
* 🔗 Combining lists with `<a>` tags to create links to songs.
* 🧩 Organizing different types of information using HTML lists.

## 💻 Technologies

* **HTML5**

## 🎯 Purpose

The purpose of this project was to review how lists work in HTML and understand the difference between **ordered and unordered lists**.

An ordered list is useful when the position or sequence of the elements matters, while an unordered list is better when we simply want to group related items together.

## 📌 What I Learned

This exercise helped me understand how HTML lists can make information easier to organize and read. I also reviewed how different HTML elements, such as `<ol>`, `<ul>`, `<li>`, and `<a>`, can be combined to create simple but structured web pages.
