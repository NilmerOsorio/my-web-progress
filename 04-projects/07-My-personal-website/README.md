# 🌐 My Personal Website

This project is a small **personal website** that I created to review and practice some fundamental concepts of **HTML, CSS, and JavaScript**.

The goal was to build a simple page containing personal information and add a small interaction using JavaScript.

## 📝 HTML

In this project, I practiced several fundamental HTML elements, including:

* Headings with `<h1>` and `<h2>`
* Paragraphs with `<p>`
* Unordered lists with `<ul>` and `<li>`
* Links with `<a>`
* Images with `<img>`
* Input fields with `<input>`
* Buttons with `<button>`
* `<div>` elements to organize the content
* Linking external CSS and JavaScript files

I also practiced using attributes such as `id`, `src`, `href`, `placeholder`, and `width`.

## 🎨 CSS

For the CSS part, I practiced controlling the size of the profile image using properties such as:

* `width`
* `max-width`
* `height`

For example, I used `width: 400px` to define the image container's width, while `max-width: 90%` helps prevent it from becoming too wide on smaller screens.

## ⚡ JavaScript

Finally, I added a small interactive feature using JavaScript.

The page contains an email input and a **Join newsletter** button. When the user clicks the button, JavaScript checks whether the input is empty.

If no email is entered, an alert appears asking the user to enter their email.

If an email is entered, JavaScript changes the content of the `<p>` element below the button and displays a personalized message.

To achieve this, I practiced:

* `document.getElementById()`
* Event listeners with `addEventListener()`
* The `click` event
* `if/else` conditional statements
* Accessing an input's value with `.value`
* Changing HTML content with `.textContent`
* Template literals using backticks

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

## 🚀 What I Learned

This project helped me understand how **HTML, CSS, and JavaScript work together**.

HTML provides the structure of the webpage, CSS controls its appearance, and JavaScript allows me to add logic and interactivity.

It was also my **first small JavaScript integration**, where I connected a button and an input from the HTML with JavaScript to create an interactive experience.
