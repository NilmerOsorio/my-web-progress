# 🌐 Web Programming Practice

Welcome to my **Web Programming Practice** folder! 🚀

In this folder, I will be uploading different projects and exercises that I create to **practice, review, and strengthen my web development skills**. 💻

The projects will cover different levels of complexity, starting with the basics and gradually moving toward more interactive websites.

### 📚 What will I practice?

* 📝 **HTML** — Basic pages, text, headings, links, lists, images, forms, and more.
* 🎨 **CSS** — Styles, colors, layouts, spacing, responsive design, and visual improvements.
* ⚡ **JavaScript** — Dynamic pages, user interactions, events, DOM manipulation, and basic logic.
* 🔗 **HTML + CSS + JavaScript** — Combining everything to create more complete and interactive web pages.

### 📂 Projects

The folder will contain projects from:

> Simple HTML exercises.
> Styled pages using HTML + CSS.
> Interactive and dynamic pages using JavaScript.
> Small projects that combine all three technologies.

The main goal is not necessarily to build complex applications, but to **practice consistently and reinforce the fundamentals of web programming**. 

### 🎯 Goal

Keep experimenting, making mistakes, fixing them, and improving with every project. 🚀

**One project at a time, one concept at a time.** 💻
