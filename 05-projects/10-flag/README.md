# 🇬🇲 Gambia Flag — CSS Fundamentals

This small project was created to practice some of the fundamental concepts of **CSS** by recreating the flag of **The Gambia** using simple HTML elements and CSS properties. 🎨

## 📚 What I Learned

While building this project, I practiced:

* 📏 Using `margin` to control the space around elements.
* ↕️ Understanding the difference between `margin-top`, `margin-bottom`, `margin-left`, and `margin-right`.
* 🎨 Changing the **background color** of HTML elements with CSS.
* 📐 Setting the **height** of elements.
* 🧩 Understanding how the size and spacing of elements affect the final design.
* 🔗 Linking an external CSS file to an HTML document.
* 🏗️ Using multiple `<div>` elements to create different sections of a design.

## 🛠️ How It Works

The flag is created using three `<div>` elements in HTML:

* 🔴 A **red** section at the top.
* 🔵 A **blue** section in the middle.
* 🟢 A **green** section at the bottom.

CSS is then used to define the color, height, and spacing of each section. The margins are particularly important because they create the white spaces that separate the colors and help reproduce the basic structure of the Gambian flag.

## 💻 Technologies

* HTML5
* CSS3

## 🎯 Goal

The main goal of this project was not to create a complex website, but to understand how basic CSS properties can be combined to create a visual design from scratch.

It was a small exercise, but it helped me become more familiar with how **HTML provides the structure while CSS controls the appearance and spacing**.
