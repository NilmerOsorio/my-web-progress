# 🔎 Google Homepage Practice

This project is a small **HTML and CSS practice exercise** where I recreated a simple version of the Google homepage.

The main goal was not to build a fully functional search engine, but to practice the basics of **HTML structure and CSS styling**, especially positioning and sizing elements.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 What I Practiced

### HTML Structure

I practiced creating a basic webpage structure using HTML elements such as:

* `<div>` to organize the content.
* `<img>` to display the Google logo.
* `<input>` to create the search field.
* `<link>` to connect the HTML document with the CSS stylesheet.

### 🎨 CSS Styling

I also practiced using CSS classes to control the appearance and position of the elements. This adds space above the main content.

For the Google logo, I practiced controlling its width and making it behave as a block element.

## 🎯 Purpose

This project is part of my **web development practice**. I'm using small recreations like this to become more comfortable with HTML and CSS before moving on to more complex interfaces and functionality.

It's a simple project, but it helped me practice an important concept:

> **Using HTML to structure a page and CSS to control how that structure looks and is positioned.**
