# 🔎 Google Homepage Clone

Welcome to my Google Homepage Clone! 🚀

In this project, I created a simple recreation of the Google search homepage using HTML and CSS. The main goal was to practice the fundamentals of web development while trying to reproduce the clean and minimalist design of Google's search page.

---

## 🛠️ Technologies Used

* 🌐 **HTML5** — Used to create the main structure and elements of the webpage (`<img>`, `<input>`, `<button>`).
* 🎨 **CSS3** — Used to style the page, organize the layout, and handle precise element positioning.

---

## 📌 About the Project

The project recreates the core elements found on the classic Google homepage:
* 🖼️ Centered Google logo (`google.png`)
* 🔍 Styled search input bar with rounded borders
* 🔘 Action buttons (`Google Search` and `I'm Feeling Lucky`)

> **💡 Development Note:** While building the CSS for this project, I collaborated with AI as a tool to assist with styling details (such as handling `calc()` offsets and element centering). However, this was done with strict criteria—reviewing, understanding, and deliberately integrating every rule rather than doing a blind copy-paste. 🧠✨

---

## 🎯 Purpose

The main purpose of this project is to practice and improve my web development skills. By recreating a familiar interface, I was able to practice concepts such as:
* 📦 Clean HTML structure and semantic tags
* 🎨 CSS styling and custom property management
* 📏 Margins, padding, and automatic block centering (`margin: auto`)
* 🔲 Borders and `border-radius` styling
* 🧭 Element positioning using `calc()` and display properties

---

## 📚 What I Learned

Working on this project helped me better understand how HTML structures a webpage and how CSS controls its visual presentation. I gained practical experience using properties like `box-sizing: border-box`, `max-width`, and dynamic spacing to ensure elements align properly on the screen.

---
