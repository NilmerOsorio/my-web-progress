# 🔗 HTML Anchor Tags Practice

In this small project, I reviewed how to use **anchor tags (`<a>`) in HTML** to establish navigation between different web pages.

The main goal was to understand how links can create a simple connection between pages, allowing the user to **move from one page to another and also come back**.

## 🛠️ What I Practiced

* 🔗 Using the `<a>` tag to create links.
* 🌐 Using the `href` attribute to specify the destination of a link.
* 📄 Connecting multiple HTML pages together.
* ↔️ Creating navigation that allows the user to move between pages.
* 🧩 Understanding how different HTML documents can be connected to create a simple website structure.

## 💻 Technologies

* **HTML5**

## 🎯 Purpose

This project was created as a small practice exercise to better understand the basics of **web navigation** and how hyperlinks can connect different pages, creating a more interactive and organized website.

## 📌 What I Learned

Through this project, I learned that anchor tags are one of the fundamental elements for navigating the web. Even with a simple `<a href="">` element, it is possible to connect pages and create a basic browsing experience for the user.
