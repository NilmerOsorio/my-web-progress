# 📝 Sign-up Website

In this small project, I reviewed some HTML fundamentals, such as various input types to make it possible for the user to input and submit data into the webpage.

---

## 🛠️ Technologies Used

* 🌐 **HTML5** — Used to create the main structure, headings, descriptive text, and interactive form inputs (`<input>`, `<button>`).

---

## 📌 About the Project

The project builds a basic user registration interface using core HTML elements:

* A welcoming header (`<h1>`) and descriptive text explaining platform access.
* A text input field for entering a username (`type="text"`).
* A secure input field for entering a password (`type="password"`).
* A file selection input restricted to images (`type="file"`).
* An action button to complete the sign-up process (`Sign up!`).

---

## 🎯 Purpose

The main purpose of this project is to practice core HTML concepts, specifically focusing on user input elements. By building this page, I explored how to allow users to interact with and provide data directly to an HTML document.

---

## 📚 What I Learned

Working on this project reinforced how different `input` attributes serve unique purposes:

* Using `type="text"` for standard text collection.
* Using `type="password"` to safely mask sensitive character entries.
* Using `type="file"` with the `accept="image/*"` attribute to handle image uploads.
