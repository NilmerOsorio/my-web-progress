# ⏱️ Stop-Watch

A simple stopwatch built with **HTML, CSS and JavaScript** to practise DOM manipulation, event handling and timer functions.

## ✨ Features

- ▶️ Start and pause the stopwatch.
- 🔄 Reset the timer to `00:00:00`.
- ⏱️ Display elapsed time in hours, minutes and seconds.
- 🎨 Custom interface with a landscape background and Font Awesome icons.

## 🛠️ Technologies

- **HTML5** — structured the stopwatch interface.
- **CSS3** — styled the layout, background and buttons.
- **JavaScript** — implemented the stopwatch logic and user interactions.
- **Font Awesome** — provided the play, pause and reset icons.

## 📚 What I Learnt

- **DOM manipulation:** Selecting HTML elements and updating their content dynamically.
- **Event handling:** Using `addEventListener()` to respond to button clicks.
- **Timer functions:** Using `setInterval()` and `clearInterval()` to start and pause the stopwatch.
- **Conditional logic:** Managing the transition between seconds, minutes and hours.
- **State management:** Using variables to track the timer's current status.
- **String formatting:** Adding leading zeros to keep the timer display consistent.
- **CSS layout:** Using Flexbox to centre the stopwatch on the page.

## 🎯 Purpose

This project was part of my JavaScript learning journey. I used it to practise fundamental programming concepts by building a functional application rather than simply studying the theory.
