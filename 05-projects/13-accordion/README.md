# 🎯 FAQ Accordion – DOM Practice

A small project built with HTML, CSS, and JavaScript to practise **DOM manipulation** and create an interactive FAQ accordion.

## 🛠️ Technologies Used
- **HTML5** – Structuring the questions and answers.
- **CSS3** – Styling the accordion, using Flexbox, pseudo-elements, and transitions.
- **JavaScript** – Adding interactivity through DOM manipulation.

## 📚 What I Learnt

- Selecting elements with `getElementsByClassName()`.
- Using `for` loops to iterate through HTML elements.
- Handling user interactions with `addEventListener()`.
- Understanding callback functions and the `this` keyword.
- Toggling CSS classes with `classList.toggle()`.
- Using CSS transitions and pseudo-elements to improve the user experience.
- Understanding how HTML, CSS, and JavaScript work together to create interactive webpages.

## 💡 Key Takeaway

This project helped me understand how JavaScript interacts with the DOM to respond to user actions and dynamically change webpage elements.
