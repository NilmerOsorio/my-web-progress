# 🚀 HTML News Article – Humans Have Reached Mars

With this small **news article project**, I review and practice some fundamental **HTML concepts** while creating a simple webpage about humans reaching Mars. 🔴🌌

The project focuses on using **text tags** such as headings and paragraphs, as well as **image tags** to add visual content to the article. 📝🖼️

I also practice using **`<div>` tags** to organize and divide the different sections of the HTML document, keeping the structure clean and easy to understand. 📦✨

### 🧠 HTML Concepts Reviewed

* 🏷️ **Headings** with `<h1>` and `<h3>`
* 📝 **Paragraphs** with `<p>`
* 🖼️ **Images** with `<img>`
* 📦 **Content organization** with `<div>`
* 🌐 **Basic HTML document structure**
* 🔗 **Image sources** using the `src` attribute
* 📏 **Image sizing** using the `width` attribute

### 🎯 Purpose

This project is a simple exercise to reinforce how different **HTML elements work together** to structure and display content on a webpage. 💻
