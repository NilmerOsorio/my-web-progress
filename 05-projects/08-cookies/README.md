# 🍪 Cookie Interaction

This is a small project I created to **practice JavaScript interaction with an HTML + CSS page**.

The idea is simple: when I click on the message **"Please accept our cookies!"**, a cookie image appears. When I click again, the cookie disappears.

Even though the project is very simple, it helped me understand some important concepts about how **JavaScript interacts with HTML elements and responds to user actions**. 💻

### 🧠 What did I practice?

* 🌐 **DOM Manipulation** — Accessing HTML elements from JavaScript.

* 🔎 **`getElementById()`** — Finding specific HTML elements using their IDs.

* 🖱️ **Events** — Using `addEventListener()` to detect when the user clicks an element.

* 🧩 **`innerHTML`** — Adding and removing HTML content dynamically.

* 🔀 **Conditional Logic** — Using `if` and `else` to decide what the program should do.

* 🔵 **Boolean Values** — Working with `true` and `false`.

* 🧠 **State** — Keeping track of whether the cookie is currently visible or not.

* 🔄 **Boolean Negation** — Using `!state` to switch between two states.

### ⚙️ How does it work?

The interaction follows a simple process:

> User clicks the message

> JavaScript detects the click

> The program checks the current state

> If the state is `true`, the cookie appears

> If the state is `false`, the cookie disappears

> The state is inverted

This helped me understand that JavaScript can make a webpage **react to what the user does** instead of remaining completely static.

### 📚 What I learned

One of the most important things I learned from this project was the concept of **state**.

At first, I was only thinking about:

> "How do I make the image appear?"

But I realized that the program also needs to remember what happened during the previous click.

This simple idea introduced me to a concept that I know will be important when creating more complex applications.

I also learned that writing code is not only about knowing syntax. I need to understand **what should happen, when it should happen, and what information the program needs to remember**.
