# 🪟 DOM Modal Practice

A small project I built to practice **JavaScript DOM manipulation** by creating an interactive modal window.

## 🧠 What I Learned

* Selecting elements with `getElementById()`
* Using `addEventListener()` to handle user interactions
* Working with click events and `event.target`
* Dynamically changing CSS with JavaScript
* Showing and hiding elements with `style.display`
* Using CSS `:hover`, `transition`, and `@keyframes`
* Positioning elements with `absolute`, `fixed`, and `transform`

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎯 Features

* Open the modal with a button
* Close it with the `×` button
* Close it by clicking outside the modal
* Simple CSS entrance animation

## 📌 Main Takeaway

This project helped me understand how **JavaScript can interact with the DOM and make a webpage respond to user actions.**
