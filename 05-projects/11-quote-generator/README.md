# 💬 JavaScript Quote Generator

A simple quote generator built with **HTML, CSS, and JavaScript** to practice DOM manipulation and user interaction.

Clicking the **"New Quote"** button randomly selects a quote and displays its author.

## 🎯 What I Learned

Through this project, I practiced:

* **DOM manipulation** with `querySelector()` and `innerText`
* **Event handling** with `addEventListener()`
* Working with **arrays and objects**
* Generating random values with `Math.random()` and `Math.floor()`
* Accessing array elements using indexes
* Separating HTML, CSS, and JavaScript into different files
* Styling a webpage using **CSS Flexbox** and background images
* Connecting external resources such as **Google Fonts** and **Font Awesome**

## 🔄 How It Works

```text
User clicks "New Quote"
        ↓
JavaScript detects the click
        ↓
A random index is generated
        ↓
A quote is selected from the array
        ↓
The DOM is updated
        ↓
New quote + author appear on screen
```

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📚 Main Takeaway

This project helped me understand how **JavaScript can interact with the DOM to make a static webpage dynamic and interactive**.

It was a small project, but an important step in learning how HTML, CSS, and JavaScript work together.
