# 🖼️ Centering an Image with CSS

In this practice, I learned how to **center an image horizontally on a webpage using CSS**.

I used three main CSS properties:

* `width` — sets the width of the image.
* `display: block` — makes the image a block-level element.
* `margin-left: auto` and `margin-right: auto` — automatically create equal margins on both sides, centering the image.

## 🔍 How It Works

First, `width: 900px` gives the image a fixed width of **900 pixels**.

Then, `display: block` makes the image behave as a block-level element.

Finally, these two properties:

```css
margin-left: auto;
margin-right: auto;
```

tell the browser to automatically distribute the available horizontal space equally between the left and right sides of the image.

As a result, the image is **centered horizontally** on the page.
