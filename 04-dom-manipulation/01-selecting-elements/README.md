# 🧩 DOM Manipulation — Part 1

In this exercise, I learned the basics of manipulating the **DOM with JavaScript**.

### 📚 What I Learned

* 🔎 Selecting elements with:

  * `getElementById()`
  * `getElementsByClassName()`
  * `getElementsByTagName()`
  * `querySelector()`
  * `querySelectorAll()`
* 🎨 Modifying element styles with `.style`
* 🏗️ Creating elements with `createElement()`
* ➕ Adding elements with `append()`
* ✏️ Changing content with `innerText`
* 🏷️ Managing classes with `classList`
* 🗑️ Removing elements with `.remove()`

### 💡 Practice

I created a list of my favourite anime and used JavaScript to dynamically create, modify, and remove `<li>` elements.
