# 🎯 Event Listeners

A small JavaScript project created to practice **DOM manipulation and Event Listeners**.

## 📚 What I Learned

### HTML

* Structuring a webpage with HTML5.
* Using `id` and `class` attributes.
* Linking external CSS and JavaScript files.

### CSS

* Using **Flexbox** to organize and center elements.
* Styling buttons with `:hover` and `:active`.
* Using `display: none` to hide content.
* Using CSS classes to control an element's appearance.
* Adding transitions for smoother interactions.

### JavaScript

* Selecting elements with `querySelector()`.
* Storing DOM elements in variables.
* Using `addEventListener()` to detect a `click`.
* Creating functions to handle events.
* Using `classList` with:

  * `contains()`
  * `add()`
  * `remove()`
* Using `if/else` to create toggle-like behavior.

## 🔗 How It Works

```text
User clicks the button
        ↓
Event Listener detects the click
        ↓
JavaScript adds/removes a CSS class
        ↓
CSS changes the content's visibility
```

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM
* Event Listeners

## 💡 Main Takeaway

This project helped me understand how **HTML provides the structure, CSS controls the appearance, and JavaScript adds the behavior and interactivity.**
