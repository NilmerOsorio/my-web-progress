# 🧹 Async/Await — JavaScript Practice

## 📚 What I Learned

- **`async` functions:** Declare asynchronous functions that always return a Promise.
- **`await`:** Wait for a Promise to settle before continuing execution within an async function.
- **Sequential execution:** Run asynchronous operations in order, ensuring each task completes successfully before starting the next one.
- **Promise resolution and rejection:** Use `resolve()` to fulfill a Promise and `reject()` to signal failure.
- **Error handling:** Use `try/catch` to handle rejected Promises and prevent unhandled errors.
- **Simulating asynchronous operations:** Use `setTimeout()` to simulate tasks that take time to complete.
- **Variable declarations:** Use `const` to avoid accidentally creating global variables.

## 🛠️ Practical Exercise

I created three asynchronous functions to simulate everyday chores:

- 🐕 Walking the dog
- 🧹 Cleaning the kitchen
- ♻️ Taking out the rubbish

I used `async/await` to execute these tasks sequentially and `try/catch` to handle failures.

## 🎯 Key Takeaway

`async/await` makes asynchronous JavaScript easier to read and maintain. Combined with Promises and error handling, it allows me to manage asynchronous operations in a clear, sequential structure.
