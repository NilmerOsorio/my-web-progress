# JavaScript: Asynchronous Code and Callbacks 🚀

## 📚 What I Learnt

In this lesson, I learnt about asynchronous code, the `setTimeout()` method and callback functions in JavaScript.

### 1. Synchronous vs Asynchronous Code ⏱️

- **Synchronous code** executes instructions one after another.
- **Asynchronous code** allows JavaScript to continue executing other instructions whilst waiting for an operation to complete.
- `setTimeout()` schedules a function to execute after a specified delay without blocking the rest of the program.

### 2. Callback Functions 🔄

A callback is a function passed as an argument to another function, which can be executed later.

Callbacks are useful when we want one task to run after another has finished.

### 3. Key Takeaways 💡

- JavaScript can handle synchronous and asynchronous operations.
- Functions can be passed as arguments to other functions.
- `setTimeout()` schedules a callback after a delay.
- Callbacks help control the order in which certain tasks are executed.
