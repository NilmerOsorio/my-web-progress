# 🚀 Async JavaScript Lab 01

## 📌 Overview
In this lab, I practiced the fundamentals of asynchronous JavaScript using `setTimeout()` to schedule notifications with different delays.

## 🎯 What I Practiced
- 🖥️ Using `console.log()` to display messages.
- ⏱️ Using `setTimeout()` to schedule delayed operations.
- 🔄 Understanding synchronous execution vs. asynchronous scheduling.
- 📦 Using arrow functions as callback functions.
- 🧠 Understanding how JavaScript continues executing while waiting for scheduled callbacks.

## 🛠️ Technologies
- JavaScript
- Visual Studio Code (VS Code)

## 📚 Key Takeaway
I learned how to schedule delayed operations and understand the order in which JavaScript executes instructions.
