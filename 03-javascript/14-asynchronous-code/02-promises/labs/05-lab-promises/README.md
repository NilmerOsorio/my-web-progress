# 📥 JavaScript Promises — Handling Download Success and Failure

## 🎯 What I Practised
- Creating a `Promise` using `new Promise()`.
- Using `resolve()` to handle successful downloads.
- Using `reject()` with an `Error` when an episode is unavailable.
- Handling successful outcomes with `.then()`.
- Handling errors with `.catch()`.
- Testing both successful and failed download scenarios.
- Using conditional statements to determine the Promise's outcome.

## 🧠 Key Takeaway
Promises allow JavaScript to handle asynchronous operations by defining what happens when an operation succeeds or fails. In this exercise, I simulated an episode download to practise both outcomes.
