# 🚀 AnimeHub — Promise and setTimeout()

## 📚 What I Practised

In this exercise, I practised using **JavaScript Promises** to simulate an asynchronous operation in AnimeHub.

### 🎯 Key Concepts
- **Promises:** Understanding how a Promise represents an operation that may complete in the future.
- **`setTimeout()`:** Simulating a two-second delay.
- **`resolve()`:** Returning a successful result when the operation finishes.
- **`.then()`:** Handling the successful result.
- **`.catch()`:** Preparing to handle potential errors.
- **Asynchronous execution:** Understanding why the message appears after a delay rather than immediately.

### 🛠️ Challenge
Create a `loadAnimeCatalogue()` function that returns a Promise and resolves with `"Anime catalogue loaded!"` after approximately two seconds.

### ✅ Expected Output
```text
Anime catalogue loaded!
```

### 🧠 Learning Goal
Understand how Promises resolve and how `.then()` handles their successful results, without using `async/await` or rejecting the Promise yet.
