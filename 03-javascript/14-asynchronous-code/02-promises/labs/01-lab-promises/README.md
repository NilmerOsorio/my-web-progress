# 🚀 JavaScript Promises — Server Availability

## 📚 What I Practised

In this lab, I practised using **JavaScript Promises** to simulate a server availability check for AnimeHub.

### 🧠 Concepts Learned

- **`new Promise()`** — Create a Promise to handle an asynchronous operation.
- **`resolve()`** — Fulfil the Promise when the server is available.
- **`reject()`** — Reject the Promise when the server is unavailable.
- **`.then()`** — Handle the successful result.
- **`.catch()`** — Handle errors when the Promise is rejected.

### 🛠️ What I Built

I created a `checkServer()` function that returns a Promise and checks whether the server is online. Depending on the result, it either resolves with a success message or rejects with an error.

### 🎯 Key Takeaway

I learned how to handle successful and unsuccessful Promise outcomes using `.then()` and `.catch()`, practising Promise syntax directly without `async/await`.
