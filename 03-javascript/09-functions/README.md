## 🧠 What I Learned

Through this code exploration, I gained a thorough understanding of what functions are, how they process data, and the different ways to define and use them in modern JavaScript.

### ⚙️ 1. Function Mechanics & Declarations
- **Function Statements:** Learned how to declare named functions using the `function` keyword and invoke them in loops.
- **Parameters & Arguments:** Practiced passing dynamic data into functions to execute reusable logic.
- **Default Parameters:** Learned how ES6 default parameter values (e.g., `a = 0, b = 0`) protect code from `NaN` or `undefined` errors when arguments are omitted.
- **Return Values:** Practiced returning computed values out of a function using `return`, allowing results to be stored in variables for further use.

### ✒️ 2. Syntax Variations & Types of Functions
- **Standard Function Declarations:** Traditional syntax hoisted and available throughout the scope.
- **Anonymous Functions:** Function expressions stored directly inside variables without a declared name.
- **Arrow Functions (`=>`):** Modern, concise ES6 syntax—exploring both multi-line block bodies and implicit single-line statements.

### 🔒 3. Advanced Concepts: Scope & Higher-Order Functions
- **Nested Functions & Lexical Scope:** Explored inner/outer function relationships. I learned that inner functions can access parent variables, but remain **out of scope** and inaccessible from the outside.
- **Higher-Order Functions:** Practiced treating functions as *first-class citizens* by passing function references as arguments into other functions (`applyFunction`).

### 🔄 4. Collection Iteration with Callbacks
- Utilized `.forEach()` alongside both anonymous and arrow functions to iterate through different JavaScript data structures:
  - **Arrays** (ordered indexed lists)
  - **Sets** (unique collections)
  - **Maps** (key-value pairs)
